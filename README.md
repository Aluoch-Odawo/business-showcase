## 🎯 How to Use This Repository

### For Visitors
1. Clone or download this repository
2. Open `index.html` in your web browser
3. Explore projects and contact information
4. Click on project links to view detailed code and live demos

### For Updates
To update your portfolio:

1. **Edit Project Information**
   - Modify `projects.json` with your actual projects
   - Update descriptions, links, and technologies

2. **Update Contact Details**
   - Edit the contact section in `index.html`
   - Add your actual email, phone, and social links

3. **Add Project Images**
   - Place images in the `assets/` folder
   - Update image paths in `projects.json`

4. **Customize Styling**
   - Edit the CSS in the `<style>` section of `index.html`
   - Change colors, fonts, and layout as needed

## 🎨 Customization Tips

### Change Colors
Find the gradient colors in the CSS:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```
Replace with your brand colors.

### Update Navigation Links
Edit the navigation in the `<nav>` section to add/remove menu items.

### Add More Projects
Copy a `project-card` div and paste it in the projects grid, then update the content.
